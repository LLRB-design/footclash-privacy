Politique de confidentialité – FOOTCLASH

Dernière mise à jour : Avril 2026

1. Introduction

L’application FOOTCLASH respecte votre vie privée et s’engage à protéger les données des utilisateurs.

2. Données collectées

  • Identifiant anonyme utilisateur
  • Données de jeu (scores, progression)
  • Adresse IP
  • Type d’appareil
  • Données de connexion

3. Utilisation des données

Les données sont utilisées pour :

  • Assurer le bon fonctionnement
  • Améliorer l’expérience utilisateur
  • Corriger les bugs

Base légale : intérêt légitime.

4. Services tiers

FOOTCLASH utilise :

  • Supabase (hébergement et base de données)

5. Publicités

L’application peut afficher des publicités. Des partenaires peuvent collecter des données anonymes.

6. Partage des données

Aucune donnée personnelle n’est vendue. Partage uniquement avec services techniques nécessaires.

7. Sécurité

Des mesures sont mises en place pour protéger les données.

8. Conservation

Les données sont conservées uniquement le temps nécessaire.

9. Droits des utilisateurs

  • Droit d’accès
  • Droit de rectification
  • Droit de suppression

10. Public concerné

L’application n’est pas destinée spécifiquement aux enfants.
